# 01 — ภาพรวมโปรเจค (Project Overview)

## เป้าหมาย

พัฒนาระบบแจ้งซ่อมสาธารณูปโภค (ไฟฟ้า/ประปา) สำหรับองค์กรปกครองส่วนท้องถิ่น
โดยใช้ **LINE OA** เป็นช่องทางหลักในการรับแจ้ง ติดตาม และแจ้งเตือน

## ปัญหาที่แก้

- ประชาชนแจ้งปัญหาไม่สะดวก ต้องโทรหรือเดินทางไปแจ้งที่หน่วยงาน
- ไม่สามารถติดตามสถานะได้ ไม่รู้ว่างานซ่อมถึงไหนแล้ว
- หัวหน้าช่างจัดการคิวงานด้วยมือ ไม่มีระบบ ตกหล่น
- ไม่มีข้อมูลสถิติสำหรับวิเคราะห์และวางแผน

## Flow หลักของระบบ

```
ประชาชน (LINE OA)                 Operator (Web/LINE)              ช่างซ่อม (Web/LINE)
       │                                │                                │
       ├─ แจ้งปัญหา ──────────────────► │                                │
       │  (ข้อความ+รูป+พิกัด)           │                                │
       │                                ├─ รับแจ้งเตือนทันที              │
       │                                ├─ ตรวจสอบ+จัดลำดับ              │
       │                                ├─ มอบหมายช่าง ────────────────► │
       │                                │                                ├─ รับ/ปฏิเสธงาน
       │                                │                                │  (ถ้าปฏิเสธ → Operator มอบหมายใหม่)
       │                                │                                ├─ ดำเนินการซ่อม
       │                                │                                ├─ อัปเดตสถานะ
       ◄─ แจ้งเตือนสถานะเปลี่ยน ────── │ ◄────────────────────────────── ├─ แนบรูปหลังซ่อม
       │                                │                                ├─ ยืนยันเสร็จสิ้น
       ◄─ แจ้งผลการซ่อม ────────────── │ ◄──────── รายงานผล ────────────┘
       │                                │
       │                                ├─ ดูสถิติ+รายงาน
       │                                ├─ จัดการผู้ใช้
       │                                └─ ตรวจสอบระบบ
```

## สถานะงานซ่อม (6 สถานะ)

```
reported → accepted → assigned → in_progress → completed
  (แจ้งแล้ว)  (รับเรื่อง)  (มอบหมาย)  (กำลังซ่อม)    (เสร็จ)
                                                          │
                                              cancelled ◄─┘
                                               (ยกเลิก)
```

## โครงสร้าง URL หลัก

| Path | ผู้ใช้ | หน้า |
|------|--------|------|
| `/` | ทุกคน | หน้าแรก |
| `/login` | ทุกคน | เข้าสู่ระบบ |
| `/register` | ทุกคน | ลงทะเบียน |
| `/citizen/*` | User | dashboard, แจ้งซ่อม, ติดตาม, ประวัติ |
| `/operator/*` | Operator | dashboard, รายการคำขอ, มอบหมาย, จัดการผู้ใช้ |
| `/technician/*` | Technician | dashboard, งานที่ได้รับ, อัปเดตสถานะ |
