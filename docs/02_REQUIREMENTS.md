# 02 — ข้อกำหนดระบบ (Requirements)

## ด้านระบบงาน

### 3.1 ระบบแจ้งปัญหาผ่าน LINE OA
- 3.1.1 สามารถแจ้งปัญหาสาธารณูปโภคผ่านแชทใน LINE OA ได้
- 3.1.2 สามารถส่งข้อความ รูปภาพ และพิกัดตำแหน่งได้ในแชทเดียว
- 3.1.3 สามารถเลือกประเภทปัญหาได้ 2 แบบ ได้แก่ **ไฟฟ้า** และ **ประปา**

### 3.2 ระบบบันทึกข้อมูลอัตโนมัติ
- 3.2.1 สามารถบันทึกข้อมูลการแจ้งซ่อมทุกครั้งที่ผู้ใช้ส่งเข้ามา
- 3.2.2 สามารถสร้างเลขที่แจ้งซ่อมอัตโนมัติสำหรับแต่ละรายการ
- 3.2.3 สามารถจัดเก็บข้อมูลในฐานข้อมูลอย่างเป็นระบบ

### 3.3 ระบบส่งการแจ้งเตือนไปยังโอเปเรเตอร์
- 3.3.1 สามารถส่งการแจ้งเตือนทันทีเมื่อมีการแจ้งซ่อมใหม่
- 3.3.2 สามารถแจ้งเตือนผ่าน LINE ไปยังบัญชีโอเปเรเตอร์ที่กำหนด
- 3.3.3 สามารถแสดงรายละเอียดงานเบื้องต้นในข้อความแจ้งเตือนได้

### 3.4 ระบบจัดการคิวงานและมอบหมายงาน
- 3.4.1 สามารถจัดลำดับคิวงานตามความยากและความเร่งด่วนได้
- 3.4.2 สามารถเลือกช่างซ่อมจากรายชื่อในระบบได้
- 3.4.3 สามารถส่งข้อมูลงาน (รายละเอียด รูปภาพ พิกัด) ไปยังช่าง
- 3.4.4 สามารถบันทึกเวลามอบหมายงานได้อย่างชัดเจน
- 3.4.5 กรณีช่างปฏิเสธงาน ระบบสามารถมอบหมายใหม่ได้

### 3.5 ระบบติดตามสถานะงานผ่าน LINE OA
- 3.5.1 สามารถแสดงสถานะงานซ่อมแก่ผู้แจ้งได้แบบเรียลไทม์
- 3.5.2 สามารถอัปเดตสถานะ เช่น "รอดำเนินการ กำลังดำเนินการ เสร็จสิ้น"
- 3.5.3 สามารถแจ้งเตือนผู้ใช้เมื่อสถานะเปลี่ยนแปลง
- 3.5.4 เมื่อช่างรับงาน ระบบจะแสดงสถานะ "กำลังดำเนินการ"

### 3.6 ระบบรายงานผลการซ่อม
- 3.6.1 สามารถบันทึกผลการซ่อมหลังช่างยืนยันเสร็จสิ้น
- 3.6.2 สามารถให้ช่างแนบรูปภาพหลังซ่อมได้
- 3.6.3 สามารถส่งรายงานผลกลับไปยังผู้แจ้งและโอเปเรเตอร์อัตโนมัติ

### 3.7 ระบบจัดการผู้ใช้และบทบาท
- 3.7.1 สามารถเพิ่ม ลบ และแก้ไขข้อมูลผู้ใช้ระบบได้
- 3.7.2 สามารถกำหนดบทบาทผู้ใช้ได้ 3 ประเภท ได้แก่ User, Operator, Technician
- 3.7.3 สามารถเปิดหรือปิดการใช้งานบัญชีผู้ใช้ได้

### 3.8 ระบบรายงานสถิติสำหรับ Operator
- 3.8.1 สามารถสรุปจำนวนการแจ้งซ่อมรายวันและรายเดือนได้
- 3.8.2 สามารถวิเคราะห์ประเภทปัญหาที่พบบ่อย ได้แก่ ไฟฟ้า และประปา

### 3.9 ระบบลงทะเบียนและเข้าสู่ระบบ (LINE OA)
- 3.9.1 สามารถลงทะเบียนผู้ใช้งานผ่านฟอร์มบน LINE OA ได้
- 3.9.2 สามารถเข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่านผ่าน LINE OA ได้
- 3.9.3 สามารถกำหนดสิทธิ์การเข้าถึงตามบทบาท ได้แก่ Operator, Technician
- 3.9.4 สามารถออกจากระบบ (Logout) ได้

---

## ด้านผู้ใช้ระบบ

### 4.1 ผู้แจ้ง (User/Citizen)
- 4.1.1 แจ้งปัญหาสาธารณูปโภคผ่าน LINE OA ได้
- 4.1.2 ส่งรูปภาพและพิกัดตำแหน่งประกอบการแจ้งปัญหาได้
- 4.1.3 ติดตามสถานะงานซ่อมผ่าน LINE OA ได้
- 4.1.4 รับการแจ้งเตือนเมื่อสถานะงานเปลี่ยนแปลงได้

### 4.2 หัวหน้าช่าง / ผู้ดูแล (Operator / Administrator)
> **หมายเหตุ**: Operator และ Administrator เป็นบทบาทเดียวกัน

- 4.2.1 เข้าสู่ระบบผ่าน LINE OA ได้
- 4.2.2 รับการแจ้งเตือนเมื่อมีงานซ่อมใหม่
- 4.2.3 มอบหมายงานซ่อมให้ช่างที่เหมาะสม
- 4.2.4 ติดตามความคืบหน้าของงานซ่อมทั้งหมด
- 4.2.5 จัดการข้อมูลผู้ใช้และกำหนดสิทธิ์การใช้งาน
- 4.2.6 สรุปและจัดทำรายงานผลการดำเนินงาน
- 4.2.7 วิเคราะห์ข้อมูลสถิติเพื่อปรับปรุงระบบ

### 4.3 ช่างซ่อม (Technician)
- 4.3.1 เข้าสู่ระบบผ่าน LINE OA ได้
- 4.3.2 รับหรือปฏิเสธงานที่ได้รับมอบหมาย
- 4.3.3 ดำเนินการซ่อมตามรายละเอียดที่ได้รับ
- 4.3.4 อัปเดตสถานะความคืบหน้าของงานผ่านระบบ
- 4.3.5 แนบรูปภาพหลังซ่อมเสร็จและยืนยันผลการซ่อม
